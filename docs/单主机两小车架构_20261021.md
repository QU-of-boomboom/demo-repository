# 单主机 + 两地面小车架构（2026-10-21）

## 1. 赛题 PDF 的通信结论

`de2aca5a-535d-4288-aecd-aed3d0cf5841.pdf` 是 **FPGA 创新设计赛道选题指南**，不是通信协议文档。它只说明：

- 平台：FMQL30TAI-悟净 lite，CPU/NPU/FPGA/VPU 异构；
- 要求：至少一种 AI 模型上板、至少一项 FPGA 开发、端到端闭环、可复现工程；
- 评分：方案、AI 部署、FPGA 模块、稳定性、性能、文档；
- 支持：Icraft、Procise、开发板资料、QQ 群。

**PDF 中没有**官方消息序列、MAVLink 方言、心跳/交接时序、UDP/串口参数、RSSI 上报格式或中继路由协议。因此不能把“官方通讯历程”写成 PDF 引用；当前项目的 `PROTOCOL.md`、`protocol/swarm.xml`、`mavlink_peer.py` 是**项目自定义**协议，需要明确标注为自定义 ICD。

## 2. 架构确认

是的，改成 **1 架主机 + 2 台地面小车**后：

- 主机航线写死，由飞控/机载执行器跟踪固定航点；CPU **不生成主机航迹**，只读取主机位置/进度/链路观测。
- CPU 调度器只决定：哪台小车去哪个候选站位、何时出发、何时接入/切换路由、何时返场。
- 小车是地面运动体：没有起飞、没有稳定悬停；状态为 `STANDBY → MOVING → READY`（返场 `MOVING → STANDBY`）。
- 当前 `IdealSimulation` 里的 “relay” 是历史抽象名；`vehicle_kind=ground_car` 时已跳过 `TAKEOFF/SETTLING`，ETA 只算路程/速度，不再加 2s 起飞和 0.5s 稳定。
- 旧的三机链式路径仍保留用于 P0 存档；新架构默认只有两台地面小车承担地面—主机最后一跳，地面站—小车为骨干。

## 3. 建议通信流程（自定义，不是 PDF 官方）

| 阶段 | 方向 | 消息 | 关键字段 |
|---|---|---|---|
| 启动 | 小车 → 地面站 | `HELLO` / `HEARTBEAT` | car_id、pose、battery、ready、timestamp |
| 启动 | 主机 → 地面站 | MAVLink `HEARTBEAT` / `GLOBAL_POSITION_INT` | sysid、lat/lon/alt、heading、armed |
| 任务 | 地面站 → 小车 | `MOVE` | task_id、car_id、station、route、eta_s、deadline |
| 接受 | 小车 → 地面站 | `MOVE_ACK` | task_id、accepted、reason |
| 执行 | 小车 → 地面站 | `TELEMETRY` 10Hz | pose、speed、progress、battery、state |
| 到位 | 小车 → 地面站 | `ARRIVED` | task_id、pose、误差、timestamp |
| 就绪 | 地面站 ↔ 小车 | `READY_CHECK` / `READY` | 定位有效、停车稳定、链路探测结果 |
| 切换 | 地面站 → 小车/主机 | `ROUTE_PREPARE` → `ROUTE_COMMIT` | route_epoch、路径、旧路径、超时 |
| 确认 | 小车/主机 → 地面站 | `ROUTE_ACK` | epoch、成功/失败、测量时间 |
| 释放 | 地面站 → 旧小车 | `RELEASE` | 仅在新路径 ACK 后 |
| 失联 | 小车本地 | 超时保持/返场 | 心跳超时、最后任务、安全位置 |
| 返场 | 地面站 → 小车 | `RETURN` | 目标 home、优先级、是否仍被链式依赖 |

数据面：地面站/主机/小车各自把相邻链路 RSSI、时间戳、valid 标志送 `LinkMonitor`；CPU 只用 `time_s` 之前、未过期的有效观测。链路质量仍是六条物理跳的最弱 hop，不用 +6dB。

主机失联时，主机按机载 ArduPilot failsafe 继续固定航线/返航；地面站不能依赖“地面站还在”作为主机飞控前提。小车失联时保持当前任务或按配置返场，不能假装 READY。

## 5. 运行新车配置

根目录新增 [mission_profile_1drone_2cars.json](../mission_profile_1drone_2cars.json)：`vehicle_kind=ground_car`、`takeoff_s=0`、`settle_s=0`、小车速度 1.5 m/s。

```powershell
# 任选其一
.\run_cars.ps1
# 或手动指定 profile
$env:MISSION_PROFILE = (Resolve-Path mission_profile_1drone_2cars.json).Path
.venv-rssi\Scripts\python.exe swarm_cooperation\swarm_cooperation\demo.py --mode none --rounds 1 --quiet --output outputs_v2/p0_cars/demo
.venv-rssi\Scripts\python.exe tests\test_car_profile.py -v
```

已验证：1 轮 46m 完成，轨迹中没有 TAKEOFF/SETTLING，只有 MOVING/READY/STANDBY。默认 `mission_profile.json` 仍是经过 P0 验收的 relay-drone 配置；新车配置是独立 variant，不覆盖旧基线。
