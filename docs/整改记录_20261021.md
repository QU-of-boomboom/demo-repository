## 本次改动

1. **唯一配置**：新增根目录 `mission_profile.json`（schema `mission-profile-v1`）和 `ideal_sim/profile.py`。`contract.py`、`ExperimentConfig`、基线脚本都从它读取；profile 校验航线 23 格、12 个占用格、6 跳、5 路径、0.1s 槽、`gain_db=0`。
2. **调度门控**：`SchedulingState` 增加 `relay_status`/`relay_eta_s`；TAKEOFF/MOVING/SETTLING 中继在候选里强制为 `None`；`_plan_targets` 不再把在飞中继改派回家。新增候选排除、ETA 递减、移动中继强 RSSI 仍不可用的测试。
3. **观测纪律**：`LinkMonitor.inject_outage(link, start, end)` 支持逐跳 1–3s 注入；`RouteController` 连续 N 槽弱链路才切、恢复需连续 3 槽高于 -72dBm；硬断链仍立即降级。新增无可行路径返回 `None`、旧路径保留但不可用的测试。
4. **基线**：`compare_baselines.py` 按 profile 的 5 个种子、每场景 5 个完整往返跑 `reactive`/`predeploy`，输出断链次数/时长、最长断链、切换、中继占用率、到位成功率、总时长，存档到 `outputs_v2/p0/baselines/`。
5. **测试**：新增 `tests/test_diff_contract.py`（标准去程 230 个 0.1s 槽、三方差异、profile 单源）；A 套件从 15 增至 24，B 46，C 8，历史 A 12、历史 C 10、冻结 B legacy 1；总计 101 项、0 跳过。`demo.py --legacy` 已转发到 `legacy_v1/`，并新增 2m/3s 快照测试。
6. **归档**：旧 DoD、2 轮基线、A V1 图表/样本、B 日志移入 `deliverables/archive/`；删除失效的嵌套 `.venv`、根 `__pycache__`、测试缓存；新增 `.gitignore`。
7. **文档**：根 README、`docs/ABC统一契约与验收.md`、A/B/C 模块 README、`VALIDATION.md`、`deliverables/README.md` 与新 DoD 同步；历史设计记录保留在 `docs/history_20261020/`。
