# 无人机中继巡检仿真

Python 算法原型，场景为 FPGA 地面站、1 架主机和 2 架固定悬停中继。模拟航迹、货架遮挡、RSSI 评估、带回差的链路选择与取货事件；不依赖硬件。

## 运行

Python 3.10 或更高版本。在本文件夹打开终端：

```powershell
python -m pip install -r requirements.txt
python warehouse_relay_sim.py
python -m unittest -v
```

安装过 Matplotlib 可跳过安装命令。默认输出到脚本所在目录，重复运行会覆盖本仿真的同名输出文件。仿真使用虚拟时间，不需真实等待 47 秒。

```powershell
# 更换取货随机种子和输出目录
python warehouse_relay_sim.py --seed 42 --output-dir seed42
# 只导出逐步数据和事件，不需要 Matplotlib
python warehouse_relay_sim.py --no-plot
# 自动字体检测失败时，明确指定中文字体
python warehouse_relay_sim.py --font C:\Windows\Fonts\msyh.ttc
```

默认依次寻找 Microsoft YaHei、SimHei、Noto Sans CJK SC 等字体；没有可用中文字体则明确报错，不交付缺字图片。绘图采用 Agg 后端，可在没有桌面的环境运行。

## 已确认的路线与时间

用户已选择：**保留终点 (3,4) 和完整遍历，接受总时间 47s**。

去程顶点如下，返程严格反向重放：

```text
(0,0) → (0,4) → (1,4) → (1,0) → (2,0)
      → (2,4) → (3,4) → (3,0) → (3,4)
```

严格交替蛇形遍历四条竖线的自然落点是 (3,0)，单程 19m。为保留完整遍历并最终停在 (3,4)，补飞 x=3 上的 4m，单程共 23m。主机在 15s 首次经过 (3,4)，此时最后一列尚未遍历完；23s 完成遍历到达任务终点，取货停留 1s，24s 开始原路返回，47s 回到 (0,0)。总距离 46m，速度 1m/s。

作为独立可选对照，`--endpoint lower-right --output-dir demo_39s` 将终点明确改为 (3,0)，总时间才是 39s；默认交付采用已确认的 47s 方案。

## 模型约定

- 坐标单位 m；3 列 × 4 行、格边长 1m。货架编号是从 1 起算的 `(列,行)`，例如 `(2,4)` 表示几何范围 `[1,2] × [3,4]` 的货架格，与中继坐标 `(2,4)` 是不同语义。
- 航线沿格线。无线连线穿过货架格的内部才计遮挡；沿格线或只触碰角点不计。穿过同一列的多个货架，只计该列一次。用线段参数区间与矩形内部求交计算，不以横坐标差直接代替遮挡。
- `RSSI = -40 - 22 log10(max(d,1)) - 12 × 穿越货架列数`。`d<1m` 按 1m 参考距离封顶，包含起点重合时的 `d=0`。
- 中继 1 为 `(1,2)`，中继 2 为 `(2,4)`。各候选端到端质量分别为 `min(地面站→中继, 中继→主机) + 6dB`，同一时刻计算两跳。
- 直连低于 -75dBm，且最佳中继改善至少 3dB 时接管。直连恢复到 -72dBm 时释放中继，形成 3dB 施密特回差。使用中继期间，另一中继至少优于当前 3dB 才切换；若当前低于 -88dBm，优先选最强可用候选。
- 图和日志的“实际 RSSI”采用本步调度后的链路值；每次切换前后的 RSSI 在**同一时刻、同一位置**计算。瞬时切换不另设中断时延。
- 货架采用零宽边界的二值遮挡，所以到达下边界时直连会突然改善，离开时又明显衰减。19.0/19.1s 和 28.0/28.1s 的快速互切由此产生，是模型的边界效应。3dB 回差抑制门限附近的小幅摆动，不能消除这种大幅跃变；本模型没有额外的最短保持时间或持续恢复计时器。
- 取货点用固定随机种子 7 随机选 2～3 个不同货架，便于复现。服务点为该格左边界中点；主机首次经过时记录取货，沿途取货按瞬时事件处理。终点另模拟一次 1s 取货，不增加随机货架清单中的格数。
- D435 图像、深度估计、避障、真实取货机械动作、射频衰落和实际 NPU 执行不在本次 RSSI 调度仿真中。

## 交付文件

| 文件 | 用途 |
|---|---|
| `warehouse_relay_sim.py` | 独立主程序；几何、RSSI、调度、仿真、日志、绘图 |
| `warehouse_relay_demo.png` | 中文双子图，2325 × 1170 像素，150dpi |
| `event_log.txt` | 完整控制台任务事件与验收结果，UTF-8 |
| `events.json` | 结构化事件，含切换前后数值、模式、位置与原因 |
| `flight_samples.csv` | 全程逐步数据，UTF-8 BOM，可用 Excel 打开 |
| `summary.json` | 参数、路线、取货清单、统计与验收检查 |
| `test_simulation.py` | 几何、数值、回差、返程、时间和随机取货回归测试 |
| `validation_log.txt` | 本次实际运行的测试输出 |
| `requirements.txt` | 绘图依赖 |

CSV 列为 `time_s, x_m, y_m, rssi_dbm, mode, direct_dbm, relay_1_dbm, relay_2_dbm, phase, distance_m`。链路模式为 `direct/relay_1/relay_2`，阶段为 `outbound/terminal_pickup/return`。图左采用蓝色直连、橙色中继，去程宽实线、返程细虚线；同一条边可能多次经过，完整时间顺序以 CSV 和右图为准。灰色直连候选低于 -88dBm 不表示实际链路断开。
